# 第三方打赏入口排查

核查日期：2026-09-14。对象：`safari-main` 的 Safari macOS/iOS 工程，原版本 1.8.11；处理版本 1.8.12。评估假设：没有限定只在美国商店分发，也没有额外外部购买授权或 Apple 单独确认。

## 结论

现有实现不能作为已确认合规的多地区上架方案保留，按用户授权移除。属于审核风险判断，并非认定任何自愿打赏都违规，也不保证移除后应用的其他部分一定过审。

规则依据：开发者打赏见 3.1.1；外部付款引导及美国商店例外见 3.1.1(a)；个人赠款例外有条件限制，见 3.2.1(vii)。[Apple App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)

## 项目实证

- 弹窗“支持项目”包含 Ko-fi 和爱发电两个直接收款入口。
- Ko-fi 按钮打开扩展内的 `src/support.html`，该页面使用第三方 iframe 展示收款页面，并提供另一个外部链接。
- 爱发电按钮直接调用 `browser.tabs.create` 打开个人页面。
- 扩展没有付款解锁、会员校验或付费功能限制；未发现 IAP 或商店地区判断。
- 文案明确用于支持这个软件项目。不能仅凭“自愿”“不解锁功能”断言其适用个人间赠款例外；也没有核实收款平台及该账号的具体资金和权益安排。
- 六种语言及 macOS/iOS 共用同一份入口，当前代码不能区分适用的商店规则。

## 已处理

移除弹窗卡片、第三方 iframe 页面、开页逻辑、专用 CSS、两个标志图片、七个翻译键及其六语种生成内容。同步清理本分支 README 中的打赏段落和相关宣传图片、预览页面与旧测试，避免遗留入口。

保留“查看源码”的普通 GitHub 链接，不将其改名为捐赠或付款入口。它不是付款跳转逻辑。本次没有改动或发布远程 GitHub 页面、其他分支、Ko-fi 或爱发电账号；本地分支的文档清理不会自动更新已上线的远程页面。

新增回归检查确保扩展源目录没有打赏页、链接、翻译及图片，并验证移除后设置仍可保存。构建必须检查最终应用资源，而不能只隐藏按钮或只搜索源码；旧构建目录可能残留已经删除的文件。

## 发布范围

本次只处理第三方打赏入口。后续如果要重新加入收入功能，应根据实际平台、商店和产品模式重新评估；不能通过语言、IP、设备地区或审核状态隐藏入口。应用商店隐私资料、第三方网站接口授权、正式签名、商店截图和最终审核不在本次合规结论之内。

验证结果：70 项 Node/DOM 测试通过；7 项 WebKit 测试通过（另 1 项桌面专属测试在 iPhone 项目跳过）。从新构建目录生成 macOS 1.8.12 开发签名应用，签名完整性核验通过；检查最终扩展资源，未发现打赏页面、跳转地址、翻译键或图片，关键资源与源码一致。新包位于 `build/safari-no-donations/Build/Products/Debug/Chat Tidy.app`。这是开发验证包，不是商店分发归档；本次没有提交 App Store 审核。
