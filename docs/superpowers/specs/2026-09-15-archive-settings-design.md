# 归档管理与本地设置（已批准）

## 交付范围

- 为 main 与 safari-main 分别保留未提交的可测试改动，不自动 commit 或 push 本次功能。
- 两个分支统一升级到 1.9.0，涵盖 manifest、package、锁文件、弹窗与 Safari 工程版本。
- 保留 Safari 源码级适配和无打赏逻辑；不把 Chrome 的打赏代码带回 Safari。

## 归档管理

- ChatGPT 侧边栏小图标展开的管理菜单与扩展弹窗都提供“归档管理”入口。
- 打开独立管理面板，包含归档列表、加载更多、多选、全选已加载项、清空选择、批量恢复和批量删除。
- 保留打开 ChatGPT 原生归档管理的入口：https://chatgpt.com/#settings/DataControls/ArchivedChats。
- 在原生归档管理界面增加多选、批量恢复与批量删除工具栏，和独立面板共用批量操作逻辑。
- 操作限定当前账号与选中的会话；删除前显示数量和确认，恢复成功后从归档列表移除。
- 请求成功才更新界面，失败项保留；支持停止、进度与限流处理。分页及恢复接口必须先从当前网页行为确认，不猜测接口。
- 不持久保存归档内容、凭据或选中列表，不创建网页与原生应用之间的转发桥接。

## 设置二级菜单

- 弹窗底部增加“设置”，进入含返回按钮的二级页面。
- 主题：跟随系统（默认）、白天、黑夜；统一影响扩展弹窗和扩展注入的菜单、对话框与归档管理面板，不改网站自身主题。
- 隐藏支持菜单：默认关闭；打开后整个支持区及其折叠标题均不显示。
- Safari 保持完全无打赏支持区，隐藏支持菜单选项不引入或恢复支持区。
- 设置通过浏览器本地存储保存，重开弹窗和刷新页面后保留，旧用户自动采用默认值。

## Grok Bots

- 仅在当前活动网站为 Grok 时显示“隐藏 Bots”和“折叠 Bots”选项，默认均关闭。
- 隐藏优先于折叠；取消隐藏后按已保存的折叠偏好展示。
- 仅操作 Bots 区域，不影响普通会话；网站动态重绘后仍生效，关闭扩展后恢复原始显示。

## 实现与验证

- 归档数据、批量操作、原生界面增强分别组织，避免扩大主内容脚本的职责。
- 复用现有六种语言目录，补齐所有新增文案。
- 分别验证两个分支的默认值、本地持久化、主题实时切换、完整隐藏支持区、Grok 专属选项与组合行为。
- 归档测试覆盖分页、选中作用域、删除确认、恢复、部分失败、停止、限流、账号变化及 DOM 重绘。
- Chromium 与 WebKit 检查弹窗和管理面板；Safari 工程编译检查；测试使用虚构对话，不删除真实聊天。
- 最终交付两个分支的工作区路径、统一版本、测试结果及未提交差异。
