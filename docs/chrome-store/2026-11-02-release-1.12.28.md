# Release 1.12.28

Chrome Web Store update. The extension package is `release/chat-tidy-1.12.28.zip` (built with `npm run package`). The developer console cannot be scripted by extensions or automation ("The extensions gallery cannot be scripted"), so every dashboard step below is manual.

## What changed for review

- **No new permissions and no new hosts.** `permissions` is still `storage` only; the seven host entries are unchanged. Each site's content-script entry now also loads `library.js`, `reader-sites.js`, `layout.js`, `code.js` and `reader.js` (plus `reader.css`, `code.css`).
- **Chat enhancements inside the open conversation**:
  - an outline of the user's questions with search across the loaded messages;
  - bookmarks with tags and notes for chats and single answers, plus a bookmarks page in the popup;
  - code-block tools: line numbers, folding, per-line copy on click, and warnings for risky commands;
  - optional layout CSS: chat width, compact sidebar, hidden disclaimers, focus mode.
- **Data:** message text of the open chat is read in page memory only. Bookmarks are stored locally in `chrome.storage.local` (titles, addresses, tags, notes; for answers also the question and an answer excerpt of at most 300 characters each). Nothing is transmitted. The clipboard is written only on the user's click (`navigator.clipboard.writeText`). The privacy policy is updated accordingly (effective 2026-11-02).
- **Popup:** one "Chat enhancements" entry explaining where each feature appears; only one page shows at a time. The privacy line now mentions local bookmarks.
- **Summary text** (`extensionDescription`, all six locales) now mentions the outline, search, bookmarks and code tools. Every locale is ≤112 characters.

## Single purpose (replace)

Chat Tidy helps users organize and navigate their own conversations on supported AI chat websites:
- bulk-manage conversations from the sidebar (select, delete, archive, restore, move);
- inside an open conversation, find, bookmark and read content more easily with an outline, search, bookmarks and code-block tools.

## Host permission justification (append)

The same seven hosts now also receive the chat-enhancement scripts, which add an outline, search, bookmarks and code-block tools to the open conversation. They read only the page's rendered messages, store bookmarks locally and make no network requests.

## Notes for reviewer (≈480 characters)

1.12.28 adds chat enhancements on the same seven hosts, with no new permissions or hosts:
- an outline of the user's questions with search over loaded messages;
- local bookmarks with tags and notes;
- code-block tools (line numbers, folding, copy one line on click, risky-command warnings);
- optional layout CSS.

Nothing is sent anywhere. Bookmarks are stored in chrome.storage.local and include short excerpts (≤300 chars) only when the user bookmarks an answer. The privacy policy is updated.

To test, open any existing conversation on a supported site, then open the popup and choose "Chat enhancements".
