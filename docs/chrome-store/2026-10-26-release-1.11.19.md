# Release 1.11.19

Chrome Web Store update notes. The extension package is `chat-tidy-1.11.19.zip` (built with `npm run package`).

## What changed for review

- **New host permission:** `https://chat.z.ai/*` (content script plus `host_permissions`). It follows the same single purpose as the six existing hosts: selecting and deleting conversations from the sidebar of that website, using the page's own signed-in session. Chrome asks existing users to approve the added host when the update installs.
- Per-site content-script entries: each website loads only the scripts it uses. Declared hosts are otherwise unchanged.
- Deletion runs as a rolling pool of 1, 3, 5, 10 or 15 simultaneous requests (default 5), with automatic pause on short rate limits. No new data is collected or stored; the local setting `concurrency` keeps its key and only accepts those five values.
- Popup redesign and a larger icon; no new permissions (`storage` only).

## Host permission justification (add to the existing text)

chat.z.ai: the extension runs only on that website's chat pages to add selection checkboxes to its sidebar and, after the user confirms, deletes the selected conversations through the website's own endpoint with the user's existing session.
