# Chat Tidy

[English](README.md) | 简体中文

一款浏览器扩展，支持在侧边栏勾选并批量删除 ChatGPT、Claude 和 Grok 的聊天记录。

## 安装

本分支 `safari-main` 面向 Safari 16.4 及更新版本，工程最低系统版本为 macOS 13.3、iOS/iPadOS 16.4。Chrome/Chromium 版本保留在 `main` 分支。

用 Xcode 打开 `safari/Chat Tidy/Chat Tidy.xcodeproj`，选择 `Chat Tidy (macOS)` 或 `Chat Tidy (iOS)` scheme。为应用和扩展两个 target 配置自己的签名团队；分发时按自己的团队调整 Bundle Identifier，并同步修改安装应用的扩展设置按钮标识。构建运行后，在 Safari 扩展设置中启用 Chat Tidy，并分别允许访问三个网站。安装或更新后，请刷新网站页面。

详细构建步骤、开发签名及验证范围见 [Safari 开发说明](safari/README.md)。

## 使用

勾选聊天记录，打开“聊天”标题旁的管理菜单，即可取消选择、反选或全选当前已加载的记录。删除前核对列表，统一确认一次即可。向下滚动侧边栏可以加载更多记录。Chat Tidy 使用各网站原生的删除能力，扩展本身不提供撤销功能；Grok 使用原生软删除操作。

扩展弹窗提供启用开关、复选框显示方式、删除并发数和六种界面语言：简体中文、繁體中文、English、Français、日本語、Русский。选择隐藏复选框时，鼠标靠近聊天左侧即可展开；已勾选或获得键盘焦点的记录仍会显示复选框。

ChatGPT 和 Grok 可设置 1–3 个并发删除请求。三个网站均由发起操作页面的隔离内容脚本直接发送同源请求。Claude 调用网站原生批量删除接口，每组最多 20 条，组间间隔 500 毫秒；并发设置适用于 ChatGPT 和 Grok。遇到 403 会立即停止，不重试或切换接口；遇到限流会停止批次、进入冷却并降低并发数。点击停止可阻止尚未发出的请求，已经发出的请求无法撤回。请保持发起操作的页面打开，直到处理结束。离开页面会停止后续请求，不会自动恢复；同一网站的多个标签页通过原生 Web Locks 避免同时执行批量操作。不同网站可以各自执行，隐私浏览和不同存储分区的锁相互独立。

ChatGPT 支持原生批量归档，可通过网站设置中的“已归档聊天”恢复。Grok 尚未确认有原生聊天归档能力，因此不提供归档，也不使用本地隐藏来替代。

Cowork 使用原生会话接口，每次请求处理一个任务，不受并发设置影响。部分任务需要设备证明，扩展不会生成或复制此类证明；请求被拒绝后会停止，需使用 Claude 原生界面处理。只有收到成功响应后，记录才会从列表中消失。

Grok 的“查看全部”搜索窗口也支持复选框和顶部批量删除工具栏。在 Grok 页面打开扩展弹窗，可使用“展示全部”开关，通过原生分页接口补充侧栏聊天记录；关闭后恢复原始列表。历史记录信息仅保存在当前页面内存中，刷新后丢弃；加载请求失败时会停止。

## 隐私与兼容性

仅在 chatgpt.com、claude.ai 和 grok.com 运行。偏好设置和冷却状态保存在本地。聊天标题、标识符和会话凭据仅在执行用户请求的操作时临时使用。不使用开发者服务器，不含广告或分析追踪。网站接口变化可能影响兼容性。

Claude 的选择范围限定在当前工作区。Cowork 任务支持选择、删除和原生归档；普通 Claude 聊天不支持归档，仅选择 Cowork 任务时才可启用归档。Grok 机器人不在处理范围内。扩展调用的是网站自身接口，并非有公开文档的开发者 API；接口行为已对照网站代码核查，自动化测试使用模拟响应。

## 开发

需要 Node.js 和 npm。

```sh
npm ci
npm run build:i18n
npm run check
npm test
```

测试使用虚构聊天记录和模拟响应，不会删除真实聊天。

翻译维护在 `_locales/*/messages.json` 中。修改后运行 `npm run build:i18n`。生成的语言包支持手动切换语言，Safari 使用相同的翻译文件展示扩展清单文本。中文提供简体和繁体，不单独区分地区版本。

Safari 工程直接引用 `manifest.json`、`popup.html`、`src/`、`_locales/`、`icons/` 和 `LICENSE`，构建时复制到扩展包。不会包含开发依赖、测试或仓库文件。

此分支直接使用原生 `browser.*` API，不引入 polyfill、页面脚本消息桥、后台请求转发或 Swift 消息桥。安装应用使用 AppKit/UIKit 原生控件。
