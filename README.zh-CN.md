# Chat Tidy

[English](README.md) | 简体中文

一款浏览器扩展，支持在侧边栏勾选并批量管理 ChatGPT、Claude、Grok、Gemini、Kimi、Qwen 和 Z.ai 的聊天记录。

1.11.19 新增 Z.ai（chat.z.ai）批量删除，批量删除大幅提速（滚动请求池，可选 1、3、5、10、15 个请求真正同时进行，默认 5，遇到短暂限流自动暂停后继续，不再固定等待），弹窗界面焕新、图标放大，ChatGPT 导航栏和 Z.ai 侧栏的管理入口始终可见，并修复 Claude 侧栏图标的尺寸问题。此前还启用了海洋蓝新图标并降低页面开销：每个网站只加载所需脚本，侧栏扫描和指针跟踪的布局计算大幅减少。自 1.10.5 起适配新版 ChatGPT、Claude 和 Grok 侧边栏，新增按标题筛选，管理菜单在操作后保持展开。新版 ChatGPT 的管理入口位于左侧应用导航栏、“探索”下方；隐藏和常显模式下都始终显示，即使复选框隐藏也能一键打开菜单全选。支持无链接聊天按钮、列表刷新和滚动复用，并兼容旧版聊天链接。

## 安装

在 Chrome 或其他 Chromium 浏览器的扩展管理页面开启“开发者模式”，选择“加载已解压的扩展程序”，加载本目录。安装或更新后，请刷新网站页面。

## 使用

勾选聊天记录，打开管理菜单（新版 ChatGPT 位于左侧应用导航栏，Claude 位于首个最近对话分组的折叠标题旁，其余界面位于聊天标题旁），即可取消选择、反选或全选当前已加载的记录。菜单在操作后保持展开，全选后可直接点击删除；点击管理图标、菜单外部或按 Esc 可关闭。删除前核对列表，统一确认一次即可。菜单顶部的筛选框可按标题高亮当前已加载的聊天，按回车或点击“选中”即可把匹配项加入选择。向下滚动侧边栏可以加载更多记录。Chat Tidy 使用各网站原生的删除能力，扩展本身不提供撤销功能；Grok 使用原生软删除操作。

扩展弹窗提供启用开关、复选框显示方式、删除并发数和六种界面语言：简体中文、繁體中文、English、Français、日本語、Русский。选择隐藏复选框时，鼠标靠近聊天左侧即可展开；已勾选或获得键盘焦点的记录仍会显示复选框。新版 ChatGPT 导航栏入口在两种模式下都始终显示；其余界面标题旁的管理图标跟随同一设置：显示复选框时常驻；隐藏时悬停才出现，勾选任意一条后保持显示。

所有网站都可设置 1、3、5、10 或 15 个并发删除请求（默认 5），这些请求真正同时进行，以滚动请求池的方式持续发送，请求之间没有固定等待。Claude 从发起操作的页面发送同源请求，调用网站原生批量删除接口，每组最多 20 条；Claude 移动到项目以及 Claude Cowork 任务（归档与删除）始终逐个处理。遇到 403 会立即停止，不重试或切换接口；遇到短暂限流（Retry-After 不超过 30 秒）会暂停请求池、将并发请求数减半并自动继续，每次运行最多 3 次；暂停开始前已发出的请求再遇到限流时会并入同一次暂停，不会再次减半；没有 Retry-After 的限流只会按估计暂停一次 5 秒；限流时间更长或反复出现时会停止批次、进入冷却并将并发降为 1。点击停止可阻止尚未发出的请求，已经发出的请求无法撤回。请保持发起操作的页面打开，直到处理结束。

ChatGPT 支持批量归档。通过侧边栏管理菜单或扩展弹窗的“归档管理”，可多选、批量恢复或删除归档；网站原生归档界面也会增加批量工具。全选仅作用于已加载项，“加载更多”继续读取列表。失败项保留选择，删除前需确认。Grok 尚未确认有原生聊天归档能力，因此不提供归档，也不使用本地隐藏来替代。

Kimi 和 Qwen 支持在侧边栏批量删除。Kimi 的记录行是原生链接，删除通过网站自身的 Connect RPC 聊天服务逐条发送，使用页面已有的登录令牌。Qwen 的记录行不带标识，Chat Tidy 会读取网站自己的聊天列表，按标题和顺序匹配侧栏行；无法匹配的行以及与其他聊天同名的行不显示复选框，且只有每条所选聊天仍位于你勾选的那一行时才会执行操作。Qwen 还支持批量归档和“归档管理”，可恢复或删除已归档的对话。 Z.ai（chat.z.ai）仅支持批量删除：其侧栏记录行不带标识，Chat Tidy 会读取网站自己的聊天列表，按标题匹配，无法匹配的记录行以及与其他聊天同名的记录行不显示复选框；删除调用网站自身的单条聊天接口，使用页面已有的登录状态。

ChatGPT 和 Qwen 的聊天可通过管理菜单批量移动至项目，Claude 的聊天可移动至组：选择已有目标，或输入名称先新建再移动；新建失败时不会移动任何聊天。ChatGPT 逐条更新会话所属项目，Claude 逐条更新会话记录所属的组，Qwen 每次请求最多加入 20 条。移动后的 ChatGPT 和 Qwen 聊天会离开主列表，Claude 的聊天仍保留在最近列表中。Cowork 任务不支持移动。普通 Claude 聊天不再显示“归档”菜单项，仅当所选全部为 Cowork 任务时才出现。

弹窗高度随内容变化：折叠使用说明后不再留空，展开后默认语言下可完整显示。设置页列出了各网站支持的能力。

Cowork 使用原生会话接口，每次请求处理一个任务，不受并发设置影响。部分任务需要设备证明，扩展不会生成或复制此类证明；请求被拒绝后会停止，需使用 Claude 原生界面处理。只有收到成功响应后，记录才会从列表中消失。

Grok 的“查看全部”搜索窗口也支持复选框和顶部批量删除工具栏。在 Grok 页面打开扩展弹窗，可使用“展示全部”开关，通过原生分页接口补充侧栏聊天记录；关闭后恢复原始列表。历史记录信息仅保存在当前页面内存中，刷新后丢弃；加载请求失败时会停止。

弹窗底部“设置”可选择跟随系统（默认）、白天或黑夜，保存于浏览器本地。Grok 页面还提供“隐藏 Bots”和“默认折叠 Bots”，默认均关闭，隐藏优先；折叠只是刷新后的默认状态，之后仍可手动展开。Chrome 版本另有“隐藏支持菜单”，可连同折叠标题一起隐藏。

## 隐私与兼容性

仅在 chatgpt.com、claude.ai、grok.com、gemini.google.com、www.kimi.com、chat.qwen.ai 和 chat.z.ai 运行。偏好设置和冷却状态保存在本地。聊天标题、标识符和会话凭据仅在执行用户请求的操作时临时使用。不使用开发者服务器，不含广告或分析追踪。网站接口变化可能影响兼容性。

Claude 的选择范围限定在当前工作区。Cowork 任务支持选择、删除和原生归档；普通 Claude 聊天不支持归档，仅选择 Cowork 任务时才可启用归档。Grok 机器人不在处理范围内。扩展调用的是网站自身接口，并非有公开文档的开发者 API；接口行为已对照网站代码核查，自动化测试使用模拟响应。ChatGPT 与 Claude 的新建项目 / 组接口以及 Kimi 可选的设备风控请求头仅对照公开客户端代码核对，未在真实账号上执行。

## 开发

需要 Node.js 和 npm。

```sh
npm ci
npm run build:i18n
npm run check
npm test
npm run package   # 生成 release/chat-tidy-<version>.zip
```

测试使用虚构聊天记录和模拟响应，不会删除真实聊天。

翻译维护在 `_locales/*/messages.json` 中。修改后运行 `npm run build:i18n`。生成的语言包支持手动切换语言，Chrome 使用相同的翻译文件展示扩展清单文本。中文提供简体和繁体，不单独区分地区版本。

发布时打包 `manifest.json`、`popup.html`、`src/`、`_locales/`、`icons/` 和 `LICENSE`。
